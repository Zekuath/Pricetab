Private by design

03 / 05
0Permissions
0Accounts
0Trackers

PriceTab requests no browser permissions at all. No account, no analytics, no telemetry. Your coins, settings, portfolio and targets live in your browser's local storage and never leave the device — which is also why they don't follow you to another computer.

Prices come from public, keyless market APIs. The one thing that leaves the browser beyond a price request is a wallet address, and only if you paste one in to watch its balance — then it goes to that chain's balance provider and nowhere else.

It also means a target can only be checked while a PriceTab tab is open. Nothing runs in the background when your browser is closed: that would need a permission, and this doesn't have one.

Verify it yourself

04 / 05

A browser extension can read every page you open, so being suspicious of one is the correct instinct — including of this page, which is marketing. Below is the part that isn't: the manifest Chrome enforces, every host the code can reach, and three checks that take a minute each.

manifest.json — every key, long values shortened at …
{
  "manifest_version": 3,
  "name": "PriceTab - Crypto Charts on Every New Tab",
  "version": "1.4.0",
  "description": "Every new tab opens a live crypto chart…",
  "chrome_url_overrides": { "newtab": "index.html" },
  "action": { "default_popup": "rate.html" },
  "icons": { "16": …, "48": …, "128": … }
}

// Seven keys. None of them is "permissions",
// "host_permissions", "background" or "content_scripts".
  • Nothing to grant There is no permissions block, so Chrome has nothing to ask you about at install. That isn't a policy we promise to keep — it is the manifest, and the browser enforces it.
  • No content scripts It cannot read, change or even see the pages you visit. The extension exists on its own new tab and nowhere else.
  • Nothing runs in the background There is no service worker to run. Close the tab and the extension is not executing — which is also why a price target can only be checked when you open a tab.
  • Every network call is in two files src/api.js and src/widgets-data.js. The source contains no XMLHttpRequest, no sendBeacon, no eval, no document.cookie, and no analytics SDK of any kind.
  • Requests go out, nothing about you goes with them There is no account, no device id and no telemetry endpoint. A price request contains a coin symbol and a currency code.

Check the permissions Open chrome://extensions, find PriceTab, click Details. The permissions list is empty, and there is no "service worker" link because there is no background page.
Watch the traffic Open a new tab, press F12, choose Network and reload. Every row will be one of the hosts above. With the widgets off, a tab asks for two things: the price history and the current price — and often neither, because both are cached.
